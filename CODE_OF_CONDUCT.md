# Código de Conducta

## Nuestro compromiso

Nos comprometemos a mantener un entorno abierto, respetuoso y libre de acoso para
todas las personas que participen en este proyecto, independientemente de su edad,
identidad, experiencia, nacionalidad, apariencia, religión o nivel técnico.

## Comportamientos esperados

- Usar lenguaje claro, respetuoso e inclusivo.
- Aceptar críticas constructivas y ofrecerlas con empatía.
- Centrarse en lo que es mejor para el proyecto y para la comunidad.
- Reconocer el trabajo y las ideas de otras personas.

## Comportamientos inaceptables

- Acoso, insultos, amenazas o comentarios discriminatorios.
- Publicar información privada de terceros sin permiso.
- Interrumpir de forma reiterada discusiones o *issues*.
- Cualquier conducta que un entorno profesional considere inapropiada.

## Alcance

Este código aplica a *issues*, *pull requests*, discusiones, revisiones de código y
cualquier espacio del proyecto.

## Aplicación

Si observas una conducta inaceptable, repórtala a **jacobo.unzueta@uao.edu.co**.
Las personas mantenedoras revisarán el caso y podrán advertir, moderar o expulsar a
quien incumpla este código.
